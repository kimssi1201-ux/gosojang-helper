개인정보 처리 안내

고소장 도우미는 회원가입 없이 사용할 수 있습니다. 사건 정보가 민감할 수 있다는 점을 고려해 사이트가 처리하는 정보와 저장 위치를 아래와 같이 안내합니다.

시행일 및 최종 수정일: 2026년 8월 7일

한눈에 보는 핵심 내용

회원가입 없음

이름과 이메일로 계정을 만들거나 로그인하지 않아도 사용할 수 있습니다.

문서는 브라우저에 저장

임시저장과 불러오기는 현재 기기의 브라우저 저장공간을 사용합니다. 서비스가 별도 문서 데이터베이스를 운영하지 않습니다.

주민등록번호 미입력

주민등록번호 입력칸을 제공하지 않습니다. 제출용 초안에는 출력 후 직접 적을 수 있는 빈칸만 표시합니다.

첨부 사진 미전송

증거사진은 현재 브라우저의 미리보기와 인쇄 화면에만 사용하며 초안 생성 API로 보내거나 서버에 보관하지 않습니다.

브라우저에 저장되는 정보

사용자가 입력한 고소인·피고소인 정보, 사건 내용, 피해와 증거 설명, 생성한 초안은 자동저장 또는 저장 기능을 위해 브라우저의 로컬 저장공간에 보관될 수 있습니다.

  • 보관 위치: 사용 중인 기기의 브라우저
  • 보관 기간: 사용자가 사이트 저장정보를 지우거나 브라우저 데이터를 삭제할 때까지
  • 삭제 방법: 브라우저 설정에서 seeyou.kr의 사이트 데이터 또는 저장공간 삭제

공용 컴퓨터나 다른 사람과 함께 쓰는 기기에서는 작성 후 브라우저의 사이트 데이터를 삭제하세요.

초안 생성 기능을 사용할 때

고소장 만들기 버튼을 누르면 초안 작성에 필요한 입력 내용이 암호화된 통신으로 Cloudflare 서버 함수를 거쳐 외부 AI API에 전달될 수 있습니다. 전달 목적은 사용자가 입력한 사건 내용을 고소장 초안 형식으로 정리하는 것입니다.

  • 전달될 수 있는 내용: 사건 유형, 당사자 정보, 사건 일시와 장소, 피해사실, 피해내용, 증거 설명
  • 전달하지 않는 내용: 사용자가 첨부한 사진 파일과 브라우저에 저장된 다른 문서
  • 보호 조치: 요청 크기와 입력 길이 제한, 허용 항목 검사, 서버에서 관리하는 API 키

서비스 자체는 초안 요청 내용을 별도 데이터베이스에 저장하지 않습니다. 다만 Cloudflare와 외부 AI 제공자는 보안, 장애 대응과 서비스 운영을 위해 IP 주소, 요청 시각, 기기·브라우저 정보, 요청 데이터를 각자의 정책에 따라 처리할 수 있습니다.

Google 광고와 쿠키

이 사이트는 Google AdSense 광고 코드를 사용할 수 있습니다. 광고가 표시될 때 Google과 광고 파트너 같은 제3자는 쿠키를 브라우저에 저장하거나 읽을 수 있고, 웹 비콘, IP 주소, 광고 식별자 또는 유사한 기술을 이용해 광고 제공, 측정, 부정 사용 방지와 맞춤설정을 수행할 수 있습니다.

  • Google을 포함한 제3자 광고 사업자가 사용자의 이전 방문 기록을 바탕으로 광고를 제공할 수 있습니다.
  • 사용자는 Google 광고 설정에서 맞춤 광고 사용 여부를 관리할 수 있습니다.
  • 유럽경제지역, 영국 또는 스위스 이용자에게 필요한 경우 Google이 제공하거나 승인한 동의 화면이 표시될 수 있습니다.
