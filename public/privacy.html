 돌아가기

개인정보 처리 안내

고소장 도우미는 초안 작성을 돕기 위한 사이트입니다. 입력한 내용은 사용자가 초안을 만들고 저장할 때 필요한 범위에서만 사용합니다.

핵심 안내

회원가입 없음

계정을 만들거나 로그인하지 않아도 사용할 수 있습니다.

서버 보관 없음

저장 버튼은 이 브라우저의 임시 저장 기능을 사용합니다. 서버에 문서를 따로 보관하지 않습니다.

주민등록번호 미입력

주민등록번호는 사이트에 입력하지 않습니다. 초안에는 출력 후 직접 적을 수 있는 빈칸만 표시합니다.

사진 파일 미저장

첨부한 사진은 서버에 업로드해 보관하지 않고, 현재 브라우저 화면의 미리보기와 증거 설명에만 사용합니다.

초안 생성 시 처리

고소장 만들기 버튼을 누르면 입력한 사건 내용이 서버 함수를 거쳐 초안 생성 API로 전달될 수 있습니다. 이때 초안 작성에 필요한 내용만 보내도록 길이 제한과 요청 크기 제한을 적용했습니다.

민감한 정보는 꼭 필요한 범위에서만 입력하세요. 주민등록번호, 계좌 비밀번호, 인증번호, 카드 전체번호 같은 정보는 입력하지 않는 것이 좋습니다.

제출 전 확인

  • 초안은 법률 자문이나 결과 보장을 의미하지 않습니다.
  • 확실하지 않은 내용은 단정하지 말고 확인 필요로 남겨두세요.
  • 실제 제출 전 주민등록번호, 서명 또는 날인, 관할 경찰서나 검찰청을 직접 확인하세요.
  • 증거자료 목록과 실제 첨부파일이 서로 맞는지 확인하세요.
